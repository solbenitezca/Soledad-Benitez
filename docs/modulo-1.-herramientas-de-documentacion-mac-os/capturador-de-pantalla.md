## 1. Introducción <a href="#introduccion" id="introduccion"></a>

Para las capturas de pantalla elegí **Lightshot**, una aplicación gratuita y liviana.

La Mac ya permite capturar la pantalla con Cmd + Shift + 4, pero Lightshot agrega algo útil para documentar: se puede **anotar la captura en el momento**, con flechas, recuadros y texto, antes de guardarla.

## 2. Instalar Lightshot <a href="#instalar-lightshot" id="instalar-lightshot"></a>

{% stepper %}
{% step %}
### Descargar

Abrir el **App Store** de la Mac, buscar "Lightshot Screenshot" y hacer clic en **Obtener**.
{% endstep %}

{% step %}
### Abrir

Al abrirlo aparece un ícono con forma de pluma en la barra de menú, arriba a la derecha. La aplicación queda funcionando en segundo plano.
{% endstep %}

{% step %}
### Dar permisos

La primera vez, Mac OS pide permiso para grabar la pantalla. Se activa en **System Settings → Privacy & Security → Screen & System Audio Recording**.
{% endstep %}
{% endstepper %}

## 3. Tomar una captura <a href="#tomar-una-captura" id="tomar-una-captura"></a>

{% stepper %}
{% step %}
### Activar

Presionar **Cmd + Shift + 9**, o hacer clic en el ícono de la pluma y elegir **Take screenshot**. La pantalla se oscurece.
{% endstep %}

{% step %}
### Seleccionar el área

Hacer clic y arrastrar para marcar la parte de la pantalla que se quiere capturar. El área se puede ajustar desde los bordes.
{% endstep %}
{% endstepper %}

## 4. Anotar la captura <a href="#anotar-la-captura" id="anotar-la-captura"></a>

Al seleccionar el área aparece una barra de herramientas al costado:

| Herramienta | Para qué sirve                          |
| ----------- | --------------------------------------- |
| Lápiz       | Dibujar a mano alzada                   |
| Línea       | Trazar líneas rectas                    |
| Flecha      | Señalar un botón o un elemento          |
| Rectángulo  | Encerrar una zona                       |
| Marcador    | Resaltar texto                          |
| Texto       | Escribir una nota sobre la imagen       |
| Color       | Cambiar el color de las anotaciones     |
| Deshacer    | Borrar la última anotación (Cmd + Z)    |

{% hint style="info" %}
📸 Captura pendiente: un área seleccionada con la barra de herramientas visible.
{% endhint %}

## 5. Guardar y usar la captura <a href="#guardar-y-usar" id="guardar-y-usar"></a>

En la barra inferior del área seleccionada están las opciones para terminar:

* **Guardar** (Cmd + S): guarda la imagen como archivo en la computadora.
* **Copiar** (Cmd + C): la copia al portapapeles, para pegarla directo en Gitbook con Cmd + V.
* **Subir**: la sube a la nube de Lightshot y devuelve un enlace para compartir.
* **Cerrar** (Esc): cancela la captura.

Para esta wiki uso la opción de copiar y pego la imagen en la página que estoy editando.
